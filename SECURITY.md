# Security

Please report vulnerabilities in the Skydropx MCP server privately to
**hola@skydropx.com** with the subject "MCP security". Do not open a public
issue for security reports.

Include what you found, how to reproduce it and its impact. We will
acknowledge the report and keep you informed while we fix it.

Security and data handling for the hosted service are described at
https://mcp.skydropx.com/legal/security.
